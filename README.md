# 📚 Independent Bookstore Events

A responsive and user-friendly web application developed using *HTML5, CSS3, and Vanilla JavaScript*. The application showcases upcoming bookstore events, allowing users to search for events and register easily through a simple interface.

## ✨ Features

- 📖 Display upcoming bookstore events
- 🔍 Search events by title
- 📱 Fully responsive design for mobile, tablet, and desktop
- ⏳ Loading indicator while events are loading
- ❌ "No Data Found" message when no matching events exist
- ✅ Form validation with error highlighting
- 🔒 User input sanitization to prevent XSS attacks
- ♿ Accessibility support using semantic HTML and ARIA labels
- 📊 Analytics event logging in the browser console

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
